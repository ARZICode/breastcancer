# Beyond the Ribbon 🎗️

An independent breast cancer awareness digital campaign concept built to know the signs, separate myth from fact, and encourage early detection conversations.

## Features
- **The Signs**: Interactive disclosure cards detailing common symptoms.
- **Myth vs. Fact**: Flip-style cards breaking down widespread misconceptions.
- **Early Detection**: Tabbed guides featuring screening recommendations from WHO, ACS, and Lebanon's MoPH.
- **Hope & Support**: Dedicated support pillars for patients, loved ones, and caregivers.
- **Take Action**: Practical 5-step guide and easy one-click share tools.

## Tech Stack
- **Framework**: React.js (Vite)
- **Styling**: Pure CSS with responsive mobile layouts and modern animations.
